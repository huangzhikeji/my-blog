# 部署到腾讯edgeone/pages上的静态博客

图片配置总结

图片位置	变量名	建议尺寸	支持格式

LOGO	logoImageUrl	120x120	PNG/JPG/GIF/SVG

页眉背景	headerBgImageUrl	1400x300	JPG/PNG

简介卡片背景	cardBgImageUrl	800x400+	JPG/PNG（全图自适应）

背景图自适应说明

简介卡片背景图会：

自动铺满整个卡片区域

保持图片比例不变

自动居中显示

超出部分自动裁剪

图片来源推荐

免费图库：Unsplash、Pexels、Pixabay

图床服务：SM.MS、Imgur、七牛云

GitHub 仓库：上传到 images 文件夹，使用相对路径
